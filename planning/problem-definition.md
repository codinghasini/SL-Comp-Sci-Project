1. User or client: Students would be the main users/clients for this
solution.
2. Problem: Technology disrupts many students when they are trying to
study, so this program would help fix that problem.
3. Proposed solution: It will allow the user to have a timer that can help
them keep track of their studying hours, analytics on how much the user
has studied per week, a library type of environment to help users to
focus, and option that allows for study breaks and to log to do items.
4. Success criteria:
- Timer accuracy
- Data management
- To do management
- Break scheduling
- Focus impact
5. Investigation: What visual elements/features in the library environment
will be the most effective in order to keep the user focused and not
distracted by other apps.
