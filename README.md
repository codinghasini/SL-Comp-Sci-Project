# SL-Comp-Sci-Project
----------------------------
Brainstormed ideas:

Idea 1:
One main problem students have when it comes to studying or homework is their phones/technology. Phones/technology are a big distraction when it comes to getting work done. It prolongs procrastination and can cause a student to fall behind. So the first idea that I thought of is a study app timer. A user might struggle with staying focused on their work, my program would help the user by shutting off whatever is distracting them and offering them a timer that can help them stay track. The program would include stuff for breaks the user might need, implementation that turns off distracting factors like social media, and it will mock an environment like a library to keep the student motivated. 

Idea 2:
My second idea is a book tracker. This program would be catered towards anyone who wants to keep track off the list of books they have read and calculate the amount of the hours they have read that week. A user might experience trouble with keeping track of their reading habits so the program would be a direct solution for them. 

Idea 3: 
My third idea is a cooking app. The program would give the user a list of recipes for the user to use and each recipe will contain in depth instructions. The app will also contain a timer for the user to use in order to keep track of their cooking in real life. The app could also included a folder for favorited recipes for the user to look back to if they want to cook it again. 






Pathway: IB SL
